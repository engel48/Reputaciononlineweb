## Build Configuration

### Nixpacks Setup

The project uses `nixpacks.toml` for build configuration:

- **Provider**: Node.js
- **Node Version**: 20.x (latest LTS)
- **Install Command**: `npm ci --include=dev`
- **Build Command**: `npm run build`
- **Start Command**: `npm run start`

### Docker Configuration

The `.dockerignore` is configured to:
- Exclude development dependencies and caches
- **KEEP** production scripts in `scripts/` directory
- Exclude Supabase Edge Functions (deployed separately)
- Exclude SQLite database files (production uses PostgreSQL)

## Pre-Deployment Checklist

Before deploying to Coolify:

- [ ] Set all **MANDATORY** environment variables
- [ ] Verify `DATABASE_URL` points to Supabase PostgreSQL
- [ ] Verify at least one AI API key is configured
- [ ] Set `FORCE_SQLITE=false` (use PostgreSQL in production)
- [ ] Set `NODE_ENV=production`
- [ ] Test build locally: `npm run build`
- [ ] Verify standalone output exists: `ls -la .next/standalone/`
- [ ] Push changes to main branch
- [ ] Clear build cache in Coolify if previous build failed

## Common Deployment Issues

### Issue: "Could not find declaration file for module 'better-sqlite3'"

**Cause**: Build environment not installing devDependencies

**Solution**:
- Nixpacks configuration updated to use `npm ci --include=dev`
- Clear Coolify build cache and rebuild

### Issue: "Cannot find module './scripts/init-database-postgres.js'"

**Cause**: `.dockerignore` was excluding all scripts

**Solution**:
- Updated `.dockerignore` to keep production scripts
- Only excludes diagnostic/test scripts

### Issue: Nixpacks detects "deno" instead of "Next.js"

**Cause**: Presence of `supabase/` directory with Deno Edge Functions

**Solution**:
- `nixpacks.toml` forces `provider = "node"`
- Supabase functions deployed separately, excluded in `.dockerignore`

## Deployment Steps in Coolify

1. **Create New Project**
   - Repository: Your Git repository
   - Branch: `main`
   - Build Pack: Nixpacks (auto-detected)

2. **Set Environment Variables**
   - Navigate to: Settings → Environment Variables
   - Add all MANDATORY variables listed above

3. **Configure Build**
   - Build Method: Nixpacks (default)
   - Root Directory: `/` (default)
   - Install Command: Auto (uses nixpacks.toml)
   - Build Command: Auto (uses nixpacks.toml)
   - Start Command: Auto (uses nixpacks.toml)

4. **Deploy**
   - Click "Deploy"
   - Monitor logs for errors
   - Verify health check: `https://your-domain.com/api/system/status`

5. **Post-Deployment Verification**
   - Check application loads: `https://your-domain.com`
   - Verify login works
   - Test Supabase connection
   - Verify AI services respond
   - Check admin panel access

---

## Rollback Procedure

If deployment fails:

1. **Check Deployment Logs**
   - Coolify → Deployments → View Logs
   - Look for specific error messages

2. **Verify Environment Variables**
   - Settings → Environment Variables
   - Ensure all MANDATORY variables are set

3. **Clear Build Cache**
   - Settings → Clear Build Cache
   - Redeploy

4. **Rollback to Previous Version**
   - Coolify → Deployments → Previous Deployment
   - Click "Redeploy"

## Health Check Endpoint

The application provides a health check endpoint:

```
GET /api/system/status
```

**Response (Healthy)**:
```json
{
  "status": "healthy",
  "database": "connected",
  "timestamp": "2025-10-26T..."
}
```

Configure this in Coolify:
- Settings → Health Check
- Path: `/api/system/status`
- Expected Status Code: 200
- Interval: 30 seconds
- Timeout: 10 seconds
- Retries: 3
